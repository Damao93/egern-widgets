# Egern 中国电信小组件 · 玻璃界面版

保留中国电信原来的 App RSA 登录、查数与 30 分钟缓存，仅移植玻璃界面并适配展示数据。

## 导入

在 Egern 中新增远程模块，使用：

```
https://raw.githubusercontent.com/Damao93/egern-widgets/main/ChinaTelecom/ChinaTelecom_Glass.yaml
```

填写原模块使用的手机号、服务密码和设备 ID（如已设置），保留原来的流量统计选项。参数只在你自己的 Egern 中填写，不要提交到本仓库。

旧模块先保留并禁用，再启用本模块；不要同时启用两者。需要回退时禁用本模块并重新启用旧模块。

## 功能和验证范围

- 小、中、大、超大与三种锁屏尺寸。
- 话费、流量、语音和套餐用量；保留原来的已用/剩余、通用/定向开关。
- 今日已记录消耗按采样余量变化估算，不是运营商提供的全天账单，首次使用需要积累数据。
- 原登录、查询、解析及缓存后端仅对冲突的格式化函数重命名，并以文本等价测试核对。
- 14 项离线测试通过；测试数据不是用户账户数据，测试过程未向电信发送请求。
- 尚未在用户手机上完成真机验证，iOS/Egern 版本可能影响实际排版。
